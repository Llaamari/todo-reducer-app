# Todo List with Reducer

A simple Todo List mobile application built with React Native, Expo and TypeScript.

This project was developed as part of a school course. It extends the previous Todo List application by introducing the useReducer hook and a custom useTodos hook for state management.

## Features

- Add new tasks.
- Mark tasks as completed or incomplete.
- Display completed tasks with strikethrough text.
- Delete individual tasks.
- Prevent empty or whitespace-only tasks.
- Automatically clear the input field after adding a task.
- Manage the todo list using `useReducer`.
- Encapsulate state management in a custom hook.
